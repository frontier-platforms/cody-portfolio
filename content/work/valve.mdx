## Problem

Small trades businesses run on paper, texts and spreadsheets. Quotes get lost and invoices go out late. Most field service software is built for much bigger companies.

## Role

I'm co-founding Valve as a side venture. I own product direction and architecture, and I write much of the code.

## Solution

- Next.js and TypeScript on Vercel for the web app, and React Native for crews in the field.
- Supabase for Postgres, auth and row-level security, so each business sees only its own data.
- Stripe Connect, so each business is paid directly by its customers.
- A Claude-powered assistant, plus an MCP server that gives AI tools permissioned access to each business's data.
